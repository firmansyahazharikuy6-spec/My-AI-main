Pemberitahuan privasi MyAI (draf)

Belum final: Operator harus melengkapi identitas/kontak, periode retensi, praktik setiap penyedia, dan proses penghapusan serta meminta peninjauan hukum sebelum publikasi Google Play.

Akun dan autentikasi

Login Google/GitHub diproses oleh Firebase Authentication. MyAI tidak meminta kata sandi Google/GitHub. Worker menerima token Firebase dan informasi akun yang diperlukan untuk mengotorisasi permintaan.

Chat, file, dan suara

Chat dan pengaturan disimpan di browser/perangkat dan, saat masuk, dapat disinkronkan ke Firestore. Chat dapat berisi pesan, jawaban, waktu, model, dan metadata lampiran. Saat pengguna mengirim permintaan AI, prompt, konteks percakapan, instruksi, teks hasil ekstraksi file, gambar, dan/atau data terkait dapat diteruskan melalui Cloudflare Worker ke penyedia AI yang dipilih.

File dipilih dan diproses di perangkat. Isi file dikirim hanya bila diperlukan untuk permintaan yang pengguna kirim. Audio transkripsi dikirim melalui Worker ke Groq. Suara Gemini Live mengirim audio mikrofon langsung ke Google; mode kamera hanya tersedia pada web dan dapat mengirim frame kamera. Aplikasi Android ini meminta mikrofon, tetapi tidak meminta izin kamera.

Penyedia dan integrasi

Permintaan chat dapat diproses oleh Google Gemini, Groq, OpenRouter, atau NVIDIA NIM. Fitur opsional dapat memakai Cloudflare/Turnstile, Pollinations, Monid, Explorium, Canva, atau Resend sesuai konfigurasi deployment dan pilihan pengguna. Praktik retensi, pemrosesan, dan penggunaan data setiap penyedia mengikuti kebijakan penyedia tersebut; detail aktual per deployment masih harus diverifikasi operator.

Data operasional, penyimpanan, dan kontrol

Cloudflare menangani trafik Pages/Worker. Penggunaan tamu dapat memakai alamat IP dan identifier perangkat acak untuk pembatasan percobaan. Browser dapat menyimpan chat lokal, draft, preferensi, pilihan model, bahasa/tema, dan identifier tamu. Data chat akun disimpan di Firestore sesuai konfigurasi proyek.

Retensi, wilayah pemrosesan, backup, dan jadwal penghapusan lintas penyedia belum ditetapkan di repositori. Saat ini belum ada alur penghapusan akun menyeluruh di dalam aplikasi. Membersihkan data lokal tidak menghapus data cloud atau data yang sudah dikirim kepada penyedia.

Hak, kontak, dan penghapusan

Sebelum rilis, operator wajib menambahkan identitas legal, alamat kontak privasi/dukungan, dasar dan masa retensi, mekanisme permintaan akses serta penghapusan akun/data cloud, dan penjelasan transfer lintas negara. Draf ini bukan pengganti peninjauan hukum.
